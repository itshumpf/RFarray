# B1_MOVED — MISNAMED. See `docs/B3_MOVED.md`.

This file was created as the frozen pre-registration for the 2026-08-23
relocation experiment, on the operator's initial report that **B1**
(`a4:f0:0f:77:91:20`) had been moved outdoors.

**The data says otherwise.** The beacon that moved is **B3**
(`f4:2d:c9:70:72:30`): its link collapsed to 0 frames on the d0wd and 10
frames at −91 dBm on the S3, while B1's median RSSI moved 0 dB (d0wd) and
−1 dB (s3) and its frame rate was unchanged. The identification was made from
RSSI and frame rate only, before any slope was computed.

**The pre-registration and the results now live in
[`docs/B3_MOVED.md`](B3_MOVED.md)**, which reproduces the frozen text unedited
and records in its §0.0 exactly how and when the treated unit was reassigned.

This stub exists instead of a deletion because `rm` on this mount returns
`Operation not permitted` — the same restriction `docs/RIPPLE_TEST.md` §7
records. Nothing else was ever written to this path.
